# Учёт событий

Клиент-серверное приложение: веб-клиент работает в браузере на Android, Windows и Linux, локальный сервер принимает запросы и сохраняет их в текстовом файле.

## Запуск

Нужен только Python 3 (сторонние библиотеки не требуются):

```bash
python3 server.py
```

Откройте в браузере <http://localhost:8000>. Для телефона/другого компьютера в той же сети сервер при запуске печатает адрес вида `http://192.168.x.x:8000`. Если используется Wi-Fi с изоляцией клиентов, её нужно отключить; при необходимости разрешите порт 8000 в файрволе.

Настройки запуска:

```bash
python3 server.py --host 0.0.0.0 --port 8000 --data ./data/events.txt
```

## Работа с приложением

1. Выберите одно из трёх радиобатонов.
2. Нажмите **«Отправить событие»** — браузер отправляет номер события и текущее время; сервер записывает запрос.
3. Нажмите **«Показать список»** — сервер возвращает все принятые запросы (номер события и время), они отображаются в списке.

## API

- `POST /api/events` — тело `{"event": 2, "time": "2026-11-22T10:15:30.000Z"}`. Успех: `201`, `{"ok": true, "event": {"id": 1, "event": 2, "time": "..."}}`. Время приводится к UTC.
- `GET /api/events` — ответ `200`, `{"events": [{"id": 1, "event": 2, "time": "..."}]}`.
- `GET /` — веб-клиент.

Примеры запросов из терминала:

```bash
curl -X POST http://localhost:8000/api/events \
  -H 'Content-Type: application/json' \
  -d "{\"event\":1,\"time\":\"$(date -u +%Y-%m-%dT%H:%M:%SZ)\"}"
curl http://localhost:8000/api/events
```

## Хранение данных

Запросы сохраняются в `data/events.txt`: одна JSON-запись на строку (формат JSON Lines). Файл создаётся автоматически, существующие записи загружаются при старте сервера, нумерация продолжается с последнего ID. Запись и чтение защищены блокировкой для безопасной работы нескольких одновременных клиентов.

## Структура

```
server.py          HTTP-сервер и хранилище
static/index.html  разметка клиента
static/style.css   стили (адаптивные, для телефона и ПК)
static/app.js      логика клиента
data/events.txt    файл событий (создаётся при запуске)
```
